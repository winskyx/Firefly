# 链式调用

 1. 链式调用语法的核心
    在每一个成员方法末尾，都返回当前对象，也就是返回this对象
 2. java语言中，哪些类支持链式调用语法?
    StringBuffer和StringBuilder等
 ```java
 StringBuffer sb = new StringBuffer("hello");
 //sb.append(true)  --> "hellotrue"
 //sb.append(true).insert(5,123); -->"hello123true"
 sb.append(true).insert(5,123);
 ```
 3. 在JavaScript中和jQuery框架中，也支持链式调用语法
